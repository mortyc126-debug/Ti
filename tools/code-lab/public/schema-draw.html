Отрисовка

Как нарисовать то, что у тебя на сайте: паутинка, свечи, градиенты, фон/шрифты/отступы, подсветка, значки и ползунок, меняющий расчёт. Нажимай «показать».

1. Паутинка (радар) — SVG

что нужно: значения по N осям (0..1), центр и радиус. Рисуешь сетку-кольца, оси из центра и многоугольник данных — вершина каждой оси на радиусе ×значение. Это SVG-теги <polygon>/<line>.

const vals = [0.8, 0.6, 0.9, 0.4, 0.7, 0.5];   // 6 осей
// точка оси i на радиусе r:
function pt(i, r){ const a = -Math.PI/2 + i*2*Math.PI/N;
  return [cx + r*Math.cos(a), cy + r*Math.sin(a)]; }
// многоугольник данных: вершина = радиус × значение
polygon points = vals.map((v,i)=> pt(i, R*v))
из чего состоит: углы осей считаешь тригонометрией (круг делишь на N равных углов). Сетка — несколько колец того же многоугольника с радиусами R/4…R. Данные — один polygon с полупрозрачной заливкой. Поменяй vals — форма паутинки меняется.

2. Свечи — canvas

что нужно: на каждую свечу 4 числа — открытие/макс/мин/закрытие (OHLC). Фитиль = линия от макс до мин. Тело = прямоугольник от открытия до закрытия. Цвет: вверх/вниз.

const data = [[40,60,35,55],[55,58,45,48], …];  // [open,high,low,close]
data.forEach((d,i)=>{
  const [o,h,l,cl]=d, up = cl >= o;
  ctx.strokeStyle = up ? "#52F2C9" : "#FF4D7A";
  // фитиль: moveTo(x, y(h)) → lineTo(x, y(l))
  // тело:  fillRect(x-8, y(max(o,cl)), 16, высота)
});
ключ: функция y(v) переводит цену в координату (ось вниз, поэтому H - …). Зелёная если закрытие выше открытия, красная если ниже. Фитиль рисуешь первым (линия), тело поверх (прямоугольник).

3. Цветные блоки с градиентами

что нужно: свойство background со значением linear-gradient() или radial-gradient(). Указываешь направление/тип и цвета-остановки.

background: linear-gradient(135deg, #FF2FAE, #7B61FF);  // по диагонали
background: radial-gradient(circle, #52F2C9, #0E0720); // из центра
background: linear-gradient(90deg, #FF8800, #FF006E);  // слева направо
как читать: 135deg — угол направления, #A, #B — цвета перехода (можно больше двух). radial — круговой из центра. border-radius скругляет углы блока.

4. Заливка страницы, шрифт, размер, отступы

что нужно: это всё CSS-свойства. background — фон, color — цвет текста, font-family — шрифт, font-size — размер, font-weight — жирность, padding — отступ внутри, margin — снаружи.

background: #140A24;        // заливка
color: #F6F4FF;             // цвет текста
font-family: system-ui;     // шрифт (список запасных)
font-size: 18px; font-weight: 600;  // размер и жирность
padding: 20px;  margin: 14px;       // отступы внутри / снаружи
разница padding/margin: padding — воздух внутри блока (между рамкой и текстом), margin — снаружи (между блоком и соседями). Размеры в px (пиксели) или rem (кратно базовому).

5. Подсветка деталей

что нужно: выделить важное цветом/рамкой/тенью/бейджем. Приёмы: акцентный color, border-left, фоновый «чип», box-shadow (свечение).

border-left: 3px solid #FF006E;          // цветная грань слева
box-shadow: 0 8px 24px rgba(255,0,110,.15); // мягкое свечение
// бейдж: background: rgba(255,0,110,.15); color:#FF2FAE;
         padding:2px 7px; border-radius:5px;
идея: акцент — это контраст. Важное число — крупнее и ярким цветом; статус — маленьким «чипом» с полупрозрачным фоном того же тона (rgba(…, .15) = тот же цвет, но 15% непрозрачности).

6. Значок (иконка)

что нужно: три пути. Проще всего — эмодзи (📈). Масштабируемо — inline-SVG (рисуешь линиями/фигурами). Готовые наборы — библиотеки (у тебя lucide).

// линия-график значок:
<svg viewBox="0 0 24 24" fill="none" stroke="#52F2C9" stroke-width="2">
  <path d="M3 17l6-6 4 4 7-7"/>         // ломаная вверх
</svg>
<circle/> <rect/> — простые фигуры.  📈 — эмодзи.
как читать SVG: viewBox — система координат (0..24), path d="M.. L.." — «перо»: Move в точку, Line до точки. stroke — цвет линии, fill — заливка. SVG не пикселизуется при увеличении.

7. Ползунок, меняющий расчёт

что нужно: <input type="range"> + обработчик oninput, который берёт значение, ПЕРЕСЧИТЫВАЕТ и перерисовывает. Вот связь «интерфейс → расчёт → отрисовка».

<input id="r" type="range" min="5" max="30" value="16" step="0.5">
r.oninput = () => {
  const rate = +r.value;                      // 1. взять значение
  const pv = 100 / Math.pow(1 + rate/100, 3); // 2. пересчитать
  out.innerHTML = "PV = " + pv.toFixed(2);     // 3. показать
};
главное: oninput срабатывает на КАЖДОЕ движение ползунка. Внутри — та самая цепочка «взял → посчитал → нарисовал». +r.value — приведение текста ползунка к числу (иначе склеит строкой). Так у тебя ставка/период меняют доходность вживую.

Две техники рисования: SVG (теги-фигуры, не пикселизуется, удобно для графиков/иконок) и canvas (рисуешь командами из JS, быстрее для многих элементов — свечи, частицы). Стиль блоков и текста — это CSS. Интерактив — обработчики событий, пересчитывающие и перерисовывающие.
