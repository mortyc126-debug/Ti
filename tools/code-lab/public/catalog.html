Настройки лаборатории

API-ключ Mistral хранится только в локальном хранилище этого браузера и передаётся локальному серверу при запуске описания. Он не записывается в файлы проекта или очередь. Любой JavaScript на этой странице технически может прочитать ключ, поэтому не используйте его на недоверенном компьютере.

Создать куски через ИИ

Выберите язык и напишите, что дополнить. ИИ предложит новые куски, которых ещё нет в библиотеке. В библиотеку попадёт только то, что вы отметите.
