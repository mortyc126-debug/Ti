Структуры данных

Чем хранить данные — и как это ведёт себя вживую. Нажимай «запустить»: увидишь операции и результат. Главное правило — форма под задачу.
ШаблоныСхемыОтладкаСтруктуры

Массив / список

[10, 20, 30]

когда: важен ПОРЯДОК и перебор по очереди. Доступ по номеру (с 0). У тебя: свечи, доходности по дням, ряд цен.

const цены = [100, 90, 120];
console.log("первый:", цены[0], " сколько:", цены.length);
цены.push(80);                       // добавить в конец
console.log("дороже 95:", цены.filter(x => x > 95).join(", "));
как толковать: первый: 100 — доступ по индексу 0. filter вернул НОВЫЙ массив только из подходящих. Минус массива: поиск «есть ли значение X» — медленный (перебор всех). Для этого есть Set/Map ниже.

Объект / словарь

{ имя: "ОФЗ", купон: 7.1 }

когда: данные ИМЕНОВАННЫЕ и нужен мгновенный доступ по ключу. У тебя: карточка бумаги, поля периода отчётности.

const b = { имя: "ОФЗ", купон: 7.1 };
console.log("купон:", b.купон);       // по ключу через точку
b.погашение = 2041;                   // добавили поле
console.log("ключи:", Object.keys(b).join(", "));
console.log("есть 'купон'?", "купон" in b);
как толковать: доступ b.купон — мгновенный (не перебор). Object.keys даёт список полей. "купон" in b → true проверяет наличие ключа. Ключи — всегда строки.

Множество (Set)

Set {1, 2, 3}

когда: нужны только УНИКАЛЬНЫЕ и быстрая проверка «есть ли?». У тебя: какие отрасли уже есть, уникальные ИНН.

const было = [1, 2, 2, 3, 3, 3];
const уник = new Set(было);
console.log("уникальные:", [...уник].join(", "));
console.log("есть 2?", уник.has(2), " есть 9?", уник.has(9));
console.log("сколько:", уник.size);
как толковать: дубли сами исчезли (1, 2, 3). has — проверка мгновенная, в отличие от массива. Используй, когда ловишь «уже видел это?» в цикле.

Map (словарь с любыми ключами)

Map { "PRICE_TREND" => 0.3 }

когда: как объект, но ключи любые, сохраняется порядок и удобен размер/перебор. У тебя: веса методов (имя → число), кэш по ключу.

const веса = new Map();
веса.set("PRICE_TREND", 0.3);
веса.set("VOL_MOMENTUM", 0.5);
console.log("вес PRICE_TREND:", веса.get("PRICE_TREND"));
console.log("всего методов:", веса.size);
веса.forEach((v, k) => console.log("  ", k, "=", v));
как толковать: get/set вместо точки, size вместо длины. Удобнее объекта, когда ключи приходят динамически (имена методов) и нужно легко считать/перебирать.

Очередь / скользящее окно (дек)

добавил в конец → выкинул старое

когда: держишь ПОСЛЕДНИЕ N элементов. У тебя: буфер последних баров, окно индикатора. (В Python — deque(maxlen=N) делает это сам.)

let окно = [];                        // последние 3
for(const x of [10, 20, 30, 40, 50]){
  окно.push(x);                       // пришёл новый
  if(окно.length > 3) окно.shift();   // выкинули самый старый
  console.log("окно:", окно.join(", "));
}
как толковать: окно «едет»: 10 → 10,20 → 10,20,30 → 20,30,40 → 30,40,50. Старое выпадает слева (shift), новое входит справа (push). Так считают скользящие средние/волатильность.

Стек (последним вошёл — первым вышел)

push / pop

когда: вложенность, отмена, разбор скобок/тегов. Кладёшь на верх, снимаешь с верха.

function скобкиОк(s){
  const стек = [];
  for(const c of s){
    if(c === "(") стек.push(c);                 // открыли — на стек
    else if(c === ")"){ if(!стек.length) return false; стек.pop(); } // закрыли — снять
  }
  return стек.length === 0;                      // всё закрыто?
}
console.log("(a(b)) →", скобкиОк("(a(b))"));
console.log("(a(b  →", скобкиОк("(a(b"));
как толковать: true — скобки сбалансированы, false — осталась незакрытая (на стеке что-то есть). Каждая ( кладётся, каждая ) снимает. Пустой стек в конце = всё парно.

Матрица / таблица (2D-массив)

[[1,2,3],[4,5,6]]

когда: числа строками и столбцами. У тебя: ковариации, корреляции активов, траекторная матрица SSA.

const m = [[1, 2, 3],
           [4, 5, 6]];              // 2 строки × 3 столбца
console.log("элемент [1][2]:", m[1][2]);          // строка 1, столбец 2 → 6
console.log("суммы строк:", m.map(row => row.reduce((a,b)=>a+b,0)).join(", "));
как толковать: m[1][2] = 6 — сначала выбираешь строку (массив), потом элемент в ней. map(reduce) свернул каждую строку в сумму (6, 15). Так и ходят по ковариационным матрицам: cov[i][j].

Как выбирать — шпаргалка

порядок + перебор → массив · именованные поля → объект · уникальность / «есть ли?» → Set · ключ→значение динамически → Map · последние N → очередь/дек · вложенность/отмена → стек · числа 2D → матрица.

главный критерий: какая операция будет самой частой — её и делай быстрой. Часто ищешь по ключу → Map/объект. Часто проверяешь «видел ли» → Set. Часто берёшь последние → дек.
