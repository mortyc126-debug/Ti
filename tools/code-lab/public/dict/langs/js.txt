оператор присваивания — необязательная цепочка не может быть целью присваивания
оператор nullish — нельзя смешивать с && или || без группировки круглыми скобками
оператор запятая — внутри выражения выполняет последовательность выражений; в списках аргументов и параметров запятые разделяют элементы
оператор необязательной цепочки — не может быть целью присваивания, тегом шаблонной строки или непосредственным конструктором после new
оператор необязательной цепочки — new (объект?.Класс) допустим с группировкой, new объект?.Класс недопустим
флаги регулярного выражения — каждый флаг указывается не более одного раза
флаги регулярного выражения — флаги u и v нельзя использовать вместе
приватное имя класса — доступно только внутри класса, где объявлено
статический import — допустим только на верхнем уровне модуля; динамический import() допустим внутри функций и блоков
export — допустим только на верхнем уровне модуля
директива use strict — допустима в начале скрипта или тела функции; в ES-модулях строгий режим включён автоматически
default в switch — может стоять в любом месте тела switch, но допускается только один раз
параметры функции — повторяющиеся имена допустимы только в нестрогой обычной функции с простым списком параметров
for...of — объявление переменной цикла не содержит инициализатор
for...in — объявление переменной цикла не содержит инициализатор
do...while — завершающая точка с запятой необязательна благодаря автоматической вставке точек с запятой
поле класса — завершающая точка с запятой необязательна
catch — параметр ошибки можно опустить
reduce — initialValue необязателен; без него первый элемент становится начальным результатом, а пустой массив вызывает TypeError
sort — compareFn необязательна; без неё элементы сортируются как строки
стрелочная функция — не имеет собственного this, arguments, super и new.target
await — допустим внутри async-функции и на верхнем уровне ES-модуля; не допустим внутри обычной функции
for...of — of является разделителем только в заголовке цикла for...of; вне него of может быть обычным идентификатором
