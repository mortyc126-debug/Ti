Конструктор кода

Собирай код из блоков. Контейнеры (if / for / функция / клик) показывают начало { и конец } и вложенность отступом. Справа — живой код и запуск с превью.
ШаблоныКонструктор
словарик терминов

переменная — коробка со значением: let x = 5.

функция — рецепт: вход → выход. Запускается при вызове.

параметр / аргумент — имя входа в описании / значение при вызове.

return — что функция отдаёт наружу.

массив — список [10, 20]; объект — { ключ: значение }.

цикл — повтор; условие (if) — ветвление.

событие — клик и т.п.; состояние — переменная между событиями.

Нажимай «+ блок», чтобы добавлять. В контейнер блоки кладутся внутрь (по его «+ блок»).
