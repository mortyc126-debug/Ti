1Виды диаграмм — и когда что

Тип диаграммы диктует ЗАДАЧА: сравнить — столбики, динамика — линия, доли — круг, связь двух величин — точки, плотность — тепловая карта.

Столбики (bar)

сравнить значения между собой

<rect x y width height> на каждое число
высота = значение, x = i × шаг

Линия (line)

динамика во времени

<polyline points="x,y x,y …">
точки по порядку, соединяются

Площадь (area)

динамика + объём «под»

та же линия, но polygon
замкнут вниз до базовой линии

Круговая (pie/donut)

доли от целого (в сумме 100%)

conic-gradient(#a 0 40%, #b 40% 70%, …)
CSS сам режет круг на сектора

Точки (scatter)

связь двух величин (x и y)

<circle cx cy r> на каждую пару
cx = по X-величине, cy = по Y

Тепловая карта (heatmap)

значение в сетке цветом

сетка <rect>, цвет = f(значение)
больше — ярче/другой оттенок
общий принцип любой диаграммы: взять данные → перевести число в координату/размер/цвет (функция-масштаб y = f(значение)) → нарисовать фигуру. Меняется только фигура (rect/line/circle) и что кодирует величину (высота/позиция/угол/цвет).

2Как показать классическую математику

Три способа вывести формулу на страницу — от простого к мощному.

А. Юникод + HTML — для простого

символы прямо в тексте: ² ³ √ Σ Π ≤ ≥ ≠ · × ∞ α β μ σ, степени через <sup>, индексы через <sub>.

σ = √( Σ(xi − μ)2 / n )
σ = √( Σ(x<sub>i</sub> − μ)<sup>2</sup> / n )
когда: подписи к графикам, короткие формулы. Быстро, без библиотек. Минус: дроби и большие выражения выглядят бедно.

Б. MathML — встроено в браузер, без библиотек

специальные теги для математики: дроби <mfrac>, корни <msqrt>, степени <msup>. Браузер сам красиво верстает.

когда: нужна настоящая вёрстка (дроби «этажами», большой корень) и не хочешь тянуть библиотеку. Многословно писать, зато работает офлайн.

В. KaTeX / MathJax — для серьёзной математики

пишешь в LaTeX (\sigma = \sqrt{\frac{1}{n}\sum (x_i-\mu)^2}), библиотека рисует идеально.

// подключить (нужен интернет/CDN):
<link href="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css">
<script src="…/katex.min.js"></script>
katex.render("\\sigma=\\sqrt{\\frac1n\\sum (x_i-\\mu)^2}", el);
когда: много сложных формул (научная статья, учебник). Стандарт де-факто. Минус: внешняя библиотека (у нас офлайн-песочница её не грузит — но на реальной странице это 2 строки).

3Формула → код (какой знак чем становится)

Перевод одинаков всегда: математический значок = операция или цикл в коде.

в математикев коде
a + b, a − b, a·b, a/ba+b · a-b · a*b · a/b
дробь a/b (этажом)a / b (не забудь скобки: (a+b)/c)
aⁿ (степень)Math.pow(a, n) или a ** n
√aMath.sqrt(a)
xᵢ (индекс)x[i] — элемент массива
Σ (сумма по i)цикл с накоплением или arr.reduce((s,x)=>s+x, 0)
Π (произведение)arr.reduce((p,x)=>p*x, 1)
|a| (модуль)Math.abs(a)
условие (кусочная функция)if (…) … else … или a > 0 ? x : y
μ (среднее), σ (ст.откл.)свои функции из суммы/длины (ниже)

Разбор: σ = √( (1/n)·Σ(xᵢ − μ)² ) → код

σ = √( 1/n · Σ (xi − μ)2 )
// 1. μ — среднее: Σx / n
const μ = x.reduce((s,v)=>s+v, 0) / x.length;
// 2. Σ(xi − μ)^2 — сумма квадратов отклонений
const сумма = x.reduce((s,v)=> s + (v - μ)**2, 0);
// 3. /n и корень
const σ = Math.sqrt(сумма / x.length);
как читается перевод: идёшь по формуле ИЗНУТРИ наружу — сначала то, что под Σ и под корнем. μ нужна первой (от неё зависит сумма) — вот и порядок строк. Σ стала reduce, ² → **2, √ → Math.sqrt, xᵢ → x[i] (внутри reduce — это v).

Диаграмма = данные → масштаб → фигура. Формула на экране = Юникод / MathML / KaTeX по сложности. Формула в коде = значки → операции, Σ/Π → reduce, читать изнутри наружу (что нужно раньше — считаешь раньше).
