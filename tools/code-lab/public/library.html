Лаборатория кода

Шаблоны для копирования. Клик по любому слову — что оно значит. Синие слова (имена) можно править прямо в коде — поменяются во всём шаблоне.
ШаблоныКонструкторСхемы
словарик терминов (нажми, если забыл что к чему)

переменная — подписанная коробка со значением. let x = 5 — коробка x хранит 5.

const / let — создать коробку. const — менять нельзя, let — можно.

функция — рецепт: даёшь вход, получаешь выход. Лежит готовой, пока не вызовешь.

параметр — имя входа ВНУТРИ функции (в описании). аргумент — конкретное значение, что даёшь при вызове.

return — выход функции: что она отдаёт наружу.

вызов — запустить функцию: среднее(числа).

массив — список значений по порядку: [10, 20, 30]. Доступ по номеру (с 0).

объект — карточка «ключ: значение»: { имя: "ОФЗ", купон: 7 }.

ключ / значение — подпись поля и то, что в нём лежит.

индекс — номер элемента в массиве, с нуля.

цикл — повторить блок много раз (for / forEach).

условие — if: выполнить блок, только если правда.

метод — функция, «приклеенная» к значению: массив.map(...).

строка — текст в кавычках. число — без кавычек.

async / await — функция умеет ждать; await = «подожди результат» (обычно сеть).

промис — обещание результата попозже (его и ждёт await).

fetch — сходить в сеть за данными. JSON — формат данных (текст → объект).

событие — что-то случилось (клик). состояние — переменная, что живёт между событиями.
