## Правило объединения

**Не удалять ни одну сторону до появления поддержки ID-перенаправлений или алиасов.** В противном случае можно потерять связи и заметки или сломать ссылки.

При подготовке объединённой записи нужно сохранить:

1. Более полное описание, теги и aliases из записи с подчёркиваниями.
2. Все `provides/requires` из записи с суффиксом.
3. Объединение `wordNotes` по ключу позиции и содержимого; не удалять заметки только потому, что они есть в обеих версиях.
4. Все `orphanNotes` с обеих сторон.
5. Оба исходных ID как перенаправляемые идентификаторы. Поле `aliases` не использовать для ID: оно предназначено для поисковых формулировок.
