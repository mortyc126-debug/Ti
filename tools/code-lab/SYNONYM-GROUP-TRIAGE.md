# Первичная разметка смешанных групп поиска

Связанный отчёт: SYNONYM-AUDIT.md.

Статус: предложения для ручной проверки. Исходный library/_synonyms.json не менялся. Номера групп — индексы с нуля в массиве groups.

## Приоритетные группы

| Группа | Сейчас | Предлагаемое разделение |
|---:|---|---|
| 14 | отступ, padding, margin, отбивка | Разделить padding и margin. «Отступ» и «отбивка» оставить поисковыми формулировками для обеих сущностей, но не объявлять их эквивалентами. |
| 16 | рамка, граница, обводка, border, outline | Разделить border и outline. «Рамка/обводка» — неоднозначные запросы; сохранить связь через общий раздел оформления. |
| 21 | центр, выравнивание, align, center, justify-content, align-items, text-align | Разделить понятие выравнивания, значения center и отдельные CSS-свойства. Не считать названия свойств синонимами. |
| 25 | позиция, положение, position, absolute, relative, fixed, sticky | Отдельно понятие позиционирования, свойство position и четыре значения. Значения связаны с position, но не равны ему. |
| 38 | переменная, variable, var, let, const, константа | Разделить понятие переменной и объявления. var/let/const — разные формы объявления с разными правилами; «константа» ближе к const, но не к var. |
| 39 | функция, function, def, метод, lambda, стрелочная, arrow | Разделить функцию, метод, lambda и стрелочную функцию. function/def — языковые формы объявления, не универсальные синонимы. |
| 42 | массив, список, array, list, коллекция | Сохранить «коллекция» как общий класс; array и list — конкретные типы/структуры, различать по языку. |
| 43 | объект, словарь, object, dict, dictionary, map, ключ, key | Разделить объект, словарь, Map и ключ. Ключ — часть структуры, не синоним контейнера. |
| 54 | разделить, split, склеить, join | Разделить на две операции: split (разбиение) и join (соединение). Связать отношением противоположных/парных операций. |
| 60 | ошибка, исключение, try, catch, except, throw | Разделить понятие ошибки/исключения и управляющие конструкции обработки/выбрасывания. |
| 63 | файл, читать, записать, file, open, read, write | Разделить файл, открытие файла, чтение и запись. Оставить между ними типизированные связи. |
| 68 | событие, click, keydown, event, addEventListener, обработчик, listener | Разделить событие, типы событий, подписку и обработчик. click/keydown — типы событий; addEventListener — метод подписки. |
| 69 | элемент, блок, контейнер, div, DOM, узел, тег, querySelector, getElementById | Разделить DOM, узел, элемент, тег, контейнер и функции поиска. querySelector/getElementById не синонимы элемента. |
| 84 | копия, copy, clone, spread, slice, structuredClone | Разделить понятие копии, поверхностное копирование, глубокое копирование и конкретные способы/синтаксис. |
| 95 | риск, волатильность, дисперсия, risk, volatility, variance, var | Разделить риск как широкое понятие, волатильность и дисперсию как разные характеристики. var дополнительно пересекается с группой 38. |
| 97 | корреляция, ковариация, связь, correlation, covariance | Разделить корреляцию и ковариацию; «связь» оставить широкой поисковой формулировкой. |
| 101 | подмена, заглушка, monkeypatch, mock, patch, stub | Разделить mock, stub, patch и monkeypatch как разные техники. «Подмена» — общий запрос, не строгий эквивалент. |

## Пересечения между группами

Алгоритм поиска добавляет все группы, в которых встретился термин. Поэтому повтор термина связывает расширения нескольких групп:

| Термин | Индексы групп | Риск |
|---|---|---|
| float | 27, 45 | CSS float и числовой тип float |
| var | 38, 95 | объявление переменной и финансовая дисперсия/риск |
| подмена | 53, 101 | замена значения/операция replace и техники mock/stub |
| join | 54, 90 | соединение строк/элементов и объединение коллекций |

Не удалять повторяющиеся термины автоматически: в некоторых случаях это разные значения одного написания. Их следует разрешать контекстом языка/раздела или явными отношениями.

## Что не делать на этом этапе

- Не переписывать группы на основе этой таблицы автоматически.
- Не удалять слова, даже если они выглядят ошибочными или слишком общими.
- Не переносить всё содержимое группы в aliases пользовательских понятий.
- Не включать обычные отношения related/depends/uses в расширение поиска по умолчанию.
- Не менять старую выдачу до подготовки контрольных запросов и сравнения результатов.

Следующий этап — пройти остальные группы, зафиксировать язык/контекст и построить таблицу соответствий старых терминов новой модели. Каждое неоднозначное слово должно сохранять исходную группу и причину, по которой его не признали точным синонимом.
