## Дубли кода

Найдено **151 пара (302 файла)** с одинаковым кодом после нормализации переводов строк и внешних пробелов. Все 151 пары совпадают полностью по этому критерию; дополнительных групп, совпавших только после схлопывания форматирующих пробелов, не обнаружено.

Это не 151 безопасное удаление. У двух вариантов разная полезная информация:

- Варианты с ID-суффиксом вида `-mvr…`: 1 282 пояснения токенов, 151 компонентный контракт `provides/requires`, 62 старых orphan-записи.
- Варианты с подчёркиваниями в имени: 191 пояснение токенов, 342 тега и 342 варианта названия, более подробные описания (суммарно 55 331 символ против 6 282 у суффиксных вариантов).

То есть одна версия обычно несёт подробное описание, теги и aliases, другая — больше токенных пояснений и контракт компонента. Удаление любой стороны без слияния потеряет данные.

**Решение:** все 151 пары оставить кандидатами на объединение. Перед объединением нужно:
1. выбрать канонический ID;
2. объединить описания без механической склейки дублирующих фраз;
3. объединить теги и aliases с устранением точных повторов;
4. объединить пояснения токенов по координатам и тексту;
5. сохранить компонентные `provides/requires`;
6. перенести все внешние ссылки и задачи на канонический ID;
7. только после проверки ссылок убрать вторую запись транзакционно с резервной копией.

В прежнем аудите уже находилась ссылка на один из старых ID из трёх задач. Поэтому удалять записи по одному совпадению кода нельзя.

## Пояснения токенов и понятий

В паспортах обнаружено 13 310 записей `wordNotes` и 70 записей `orphanNotes`.

| Категория | Количество | Вывод |
|---|---:|---|
| Пояснения с точным совпадением текста и координат | 12 771 | Привязка подтверждена |
| Варианты с переставленными `kind` и `note` | 293 | 292 имеют точную позицию; один имеет пустой `text` и требует ручного решения |
| Совпадение с токеном в другом месте кода, единственный кандидат | 29 | Не переносить автоматически: координаты устарели |
| Несколько вхождений токена, позиция не совпала | 90 | Неоднозначно; требуется ручная проверка |
| Составной фрагмент/подстрока | 1 | Нужна проверка границ выделения |
| Текст не найден в текущем коде | 8 | Сохранить как неразрешённые заметки |
| Записи типа `concept` | 481 | Это понятия, а не подписи токенов; кандидат на перенос в модель пользовательских конструкций |
| Старые orphan-записи, уже имеющие точную копию в `wordNotes` | 70 | 35 разных заметок продублированы по два раза |

Категории частично пересекаются: 293 переставленных записи входят в число заметок с подтверждённой координатой, кроме одного пустого текста. 481 запись `concept` исключена из подсчёта привязок токенов.

### Разбор переставленных полей

Паттерн однозначен: `note` содержит тип токена (`kw`, `fn` и т. п.), а `kind` — человеческое пояснение. Для 292 записей дополнительно подтверждена точная позиция в коде. В загрузчике уже есть консервативное восстановление этого случая; оно не переписывает паспорт само по себе, а нормализует структуру при следующем сохранении.

Одна запись в `js/вызов-функции-если-она-есть.js.meta.json` имеет пустое поле `text`; восстановить выделенный токен только по текущим данным нельзя. Она не должна автоматически становиться подписью `?.()` без подтверждения.

### Разбор 481 записей типа concept

Они лежат в `wordNotes`, но обозначают не токен, а понятие/тему фрагмента. Например: «делегирование событий», «DOM», «проверка параметров», «асинхронность». Это не потерянные пояснения и не мусор. Их нужно перенести в отдельные понятия/ключевые темы при реализации модели конструкций, сохранив ссылку на исходный фрагмент и текст пояснения.

### 70 старых orphan-записей

Все 70 имеют полное совпадение с уже существующей записью `wordNotes` того же паспорта (35 разных заметок встречаются в orphan дважды). Это безопасные кандидаты на удаление именно из `orphanNotes`, но сами `wordNotes` удалять нельзя. В текущем этапе данные не менялись.

### 8 заметок, отсутствующих в коде

- 2 пользовательские заметки `N` в `python/math-ssa.py`: текущий код использует `L`, но пояснение «длина ряда» не подходит к `L` без уточнения смысла.
- 4 словарные заметки `returns` в `python/var-по-истории-mvh8gqxd.py`: код переведён на имя `доходности`; координаты также не совпадают с текущим кодом.
- 2 словарные заметки `for` в `python/асинхронное-ожидание-нескольких-сокетов-mvkjwp8b.py`: текущая версия кода не содержит этих циклов.

Не перепривязывать автоматически. Сохранить их как историю/неразрешённые заметки до отдельного решения.
