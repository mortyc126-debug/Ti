# Первый аудит теневого поиска поисковых фраз

Дата: 2026-11-06  
Ветка: `audit/fixes-2026-11-06`

## Объём проверки

Проверен исходный `public/dict/synonyms.json` без записи в него и без изменения рабочего индекса.

- 1 707 ключей-целей;
- 11 629 направленных фраз;
- 67 запросов из контрольного набора;
- 28 запросов дали хотя бы одну цель;
- 39 запросов не дали совпадений;
- 18 запросов дали несколько ключей-целей.

Это проверка слоя поисковых фраз по нормализованному точному совпадению, началу или вхождению строки. Она **не является полной оценкой top-5/top-10**: здесь ещё не учитывались ранжирование фрагментов, словоформы и реальная релевантность содержимого куска. Для этого предназначен HTTP endpoint `/api/search/shadow`.

## Запросы без совпадений

Следующие 39 контрольных формулировок не встретились в legacy-фразах:

- CSS/HTML: отступ внутри элемента; отступ снаружи элемента; обводка вокруг элемента; толщина шрифта; межбуквенный интервал; выровнять текст по центру; выровнять элементы по центру; расположить элемент поверх другого; обтекание изображения текстом; спрятать элемент, сохранив место; скрыть элемент из потока; плавно изменить свойство; медиазапрос для телефона.
- JavaScript/Python: объявить переменную; объявить константу; функция с именем; пройти по массиву; условие иначе; список Python; словарь Python; разбить строку по разделителю; соединить элементы массива в строку; найти элемент массива; проверить наличие элемента; округлить до двух знаков; асинхронно дождаться результата; сериализовать в JSON.
- DOM/сеть/файлы/тесты: подписаться на клик; запросить данные по HTTP; тестовая заглушка; подменить функцию в тесте; подготовка перед тестом; очистка после теста.
- Финансовые термины: волатильность актива; дисперсия доходности; корреляция двух рядов; ковариация двух рядов; доходность облигации; эмитент облигации.

Вывод: старый словарь не покрывает значительную часть контрольных формулировок. Это не повод автоматически дописывать их в legacy-словарь: новые формулировки должны добавляться отдельно, с источником и назначением.

## Неоднозначные и подозрительные результаты

| Запрос | Полученные цели | Замечание |
|---|---|---|
| стрелочная функция | `lambda`, `lambda x` | Python lambda не тождественна JS arrow function |
| ключ словаря | `__hash__(self)`, `del`, `frozenset`, `frozenset(it)`, `hash(...)`, `typeerror unhashable` | несколько разных аспектов работы ключей; не одно понятие |
| найти элемент по id | `document.getelementbyid`, `id` | `id` — атрибут/идентификатор, не операция поиска |
| округлить вниз | `int(x, base=10)`, `math.floor` | `int()` усекает к нулю и не эквивалентен `floor()` для отрицательных чисел |
| ответ сервера | `response`, `response.json()` | разбор тела ответа — отдельная операция |
| прочитать файл | `open(path, mode, encoding)`, `read` | `open()` открывает файл, чтение выполняет отдельная операция |
| открыть файл | `open`, `open(path, mode, encoding)`, `with`, `with open` | часть целей описывает управление ресурсом, а не само открытие |
| join | `str.join(it)`, `merge`, `set.isdisjoint(o)` | `set.isdisjoint` выглядит ложным совпадением |
| подмена | исключение в `__exit__`, исключение в `finally`, `str.replace(...)` | разные смыслы слова «подмена» |
| var | `locals()`, `vars(a)`, `vars(obj)`, `co_varnames`, `nameerror`, `typevar`, `unboundlocalerror` | запрос о JS-переменной получает Python-цели |
| float | 18 целей, в том числе `float`, `float(x)`, `float.hex()`, `float_info` | без языка/раздела выдача слишком широка |
| размер | 28 целей | общий запрос собирает CSS, Python, JS и другие значения |
| найти | 41 цель | общий глагол размножает методы поиска и связанные операции |
| строка | 84 цели | чрезмерно широкая выдача для короткого запроса |
| скрыть | 7 целей | смешаны CSS, Python и общая приватность |

Эти результаты — кандидаты на ручную разметку ложных совпадений, а не автоматическое решение об удалении записей.

## Что уже подключено

Добавлен изолированный endpoint:

`GET /api/search/shadow?q=...`

Параметры: `lang`, `scope`, `limit`.

Ответ содержит:
- `legacy` — результат действующего `/api/search`;
- `shadow` — отдельные цели `targetKey`, исходные фразы, найденные разделы и связанные фрагменты;
- `ambiguous` — признак нескольких целей;
- `productionSearchChanged: false`.

Manifest собирается в памяти из legacy-словаря. Рабочие файлы не переписываются. Старый endpoint `/api/search` не изменён.
