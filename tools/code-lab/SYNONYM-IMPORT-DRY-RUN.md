## Формат переноса

Каждая исходная запись становится отдельной записью `queryPhrases`:

- `phrase` — исходная формулировка пользователя;
- `targetKey` — точный ключ legacy-словаря, к которому ведёт фраза;
- `source.file`, `source.key`, `source.index` — происхождение и позиция;
- `origin: import` — запись импортирована, а не подтверждена вручную;
- `language` и `scope` остаются пустыми: старый источник их не хранит;
- повторяющаяся фраза у нескольких ключей остаётся несколькими целевыми связями. Она не превращается в alias.

Не создаются 1 707 фиктивных пользовательских понятий: ключи сохраняются как отдельные цели legacy-индекса через `targetKey`.

## Проверка

Добавлен `lib/query-phrase-import.mjs` и команда:

```bash
node tools/code-lab/scripts/dry-run-query-phrase-import.mjs
```

По умолчанию команда только печатает сводку. Для создания отдельного manifest нужно явно указать новый путь:

```bash
node tools/code-lab/scripts/dry-run-query-phrase-import.mjs --out ./query-phrases-preview.json
```

Режим `--out` создаёт новый файл без перезаписи существующего. Он не меняет `public/dict/synonyms.json`, `library/_concepts.json`, `library/_synonyms.json` или действующий индекс.

Автотест читает полный исходный словарь, проверяет все 11 629 записей, целостность целей, неоднозначность и стабильность ID при повторном dry-run.

## Продолжение после dry-run

- Добавлен отдельный модуль `lib/query-phrase-shadow.mjs`.
- Добавлен read-only endpoint `GET /api/search/shadow?q=...` с параметрами `lang`, `scope`, `limit`.
- Endpoint возвращает действующую выдачу `legacy` и отдельные результаты `shadow`; `targetKey` не превращается в синоним.
- Manifest строится в памяти из legacy-словаря. Ни рабочее хранилище, ни исходный словарь не переписываются.
- `/api/search` не переключался и не изменялся.
- Добавлены unit-тест теневого индекса и HTTP smoke-проверка сравнения с действующей выдачей.

Первый phrase-layer прогон 67 контрольных запросов зафиксирован в `QUERY-PHRASE-SHADOW-RESULTS.md`: 28 запросов с совпадениями, 39 без совпадений, 18 с несколькими целями. Это предварительная проверка формулировок, не полное сравнение top-5/top-10.
