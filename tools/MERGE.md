# Как соединить: workspace + CodeMirror 5 + ваши куски кода

Набор ничего не заменяет целиком. В нём новые файлы и патчер `apply-cm5-patch.mjs`, который дописывает несколько
строк в ваши существующие `code-lab-server.mjs`, `app.js`, `library.html` по якорям (как ваш `apply-workspace-patch.mjs`).
Библиотеку (`code-lab/library/`), `data/`, `workspace.json` ни этот набор, ни патчеры не трогают.

## Порядок

0. Резервная копия. Лучше всего `git commit` текущего состояния (тогда `git diff` потом покажет каждую добавленную строку)
   или просто копия папок `tools` и `code-lab/library`.
1. Распакуйте архив в папку, где лежит `tools` (в `C:\Users\mortn\ti`). Ваших файлов он не перезаписывает.
2. Посмотрите, что будет сделано (ничего не меняется):
   `node tools/apply-workspace-patch.mjs --check`
   `node tools/apply-cm5-patch.mjs --check`
3. Примените (порядок любой, повторный запуск безопасен):
   `node tools/apply-workspace-patch.mjs`
   `node tools/apply-cm5-patch.mjs`
   Перед записью создаётся копия `<файл>.bak-cm5` (у workspace-патчера свои `.bak`).
4. Перезапустите сервер. «⚙ Настройки» → «Редактор кода…» → «Проверить обновления» → «Скачать и проверить» → «Включить»,
   затем Ctrl+F5 на странице библиотеки.

Если `ставили cm5-update.zip` раньше, всё равно запускайте шаг 3: патчер увидит, что уже есть, и допишет недостающее (общую защиту).

## Общая защита сервера (добавляет патчер)

Сервер умеет запускать код (`/api/run`) и, с workspace, писать файлы в выбранную папку. Без проверки адреса любая страница в
браузере, открытая пока сервер запущен, может послать ему запрос. Патчер добавляет в начало обработчика проверку для `/api/*` и `/vendor/*`:
запрос принимается только с `Host` = localhost / 127.0.0.1 / [::1] с портом сервера и без чужого `Origin`.
Ваши страницы и обычная работа не затронуты. Где это может помешать: если открываете сервер не по localhost (по IP в сети, через туннель)
или обращаетесь к API с другой страницы (другой порт, Live Server). Тогда запустите патчер с `--no-guard` или уберите блок
`// ── защита от чужих сайтов …` в `code-lab-server.mjs`.

## Если патчер пишет «НЕ НАШЁЛ место»

Значит, файл у вас отличается от того, что ожидает якорь. Ничего не испорчено (до записи ничего не пишется, а остальные шаги
выполняются). Пришлите вывод патчера, подскажу вставку для вашего файла.

## Откат

Верните `<файл>.bak-cm5` на место (или `git checkout -- <файл>`). Новые файлы можно просто удалить.
