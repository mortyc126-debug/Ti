# Схемы отраслей

Здесь лежат пользовательские «схемы анализа» по отраслям — HTML-файлы
(например, разбор банковского сектора). Структура:

```
references/schemes/<ключ-отрасли>/<имя-файла>.html
```

Ключи отраслей — из `web/src/data/industries.js` (banks, oil-gas, leasing …).

Файлы добавляются и удаляются **из приложения** (раздел «Схемы отраслей»)
через GitHub Contents API — каждое действие делает отдельный коммит в этот
репозиторий. В приложении файлы подгружаются **лениво**: список — при открытии
отрасли, содержимое — при открытии конкретного файла; при старте ничего из них
не грузится.
